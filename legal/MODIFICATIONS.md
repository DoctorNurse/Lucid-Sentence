# Modifications to ONLYOFFICE software

Lucid Sentence's document engine is based on the original ONLYOFFICE software
developed by Ascensio System SIA. This log records how the version we ship
differs from upstream, as the ONLYOFFICE additional terms require (see
[`/NOTICE`](../NOTICE)). Upstream sources are pinned in
[`engine/manifest.json`](../engine/manifest.json).

| Date       | Component                                    | Change                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ---------- | -------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2026-10-09 | sdkjs 9.4.0 (release/v9.4.0 @ d8e4124)       | Built word-only with `build/build.py --addon engine/sdkjs-addon`. The addon (`engine/sdkjs-addon/lucid/bridge.js`) replaces `baseEditorsApi.prototype._openEmptyDocument` so offline documents open from a binary the app supplies (or sdkjs's blank document), and adds `window.LucidBridge` (export the document binary, list media, reset the saved state, list paragraphs/styles, report the list type at the cursor). The license header of the built files states that this is a modified version and the build date. |
| 2026-10-09 | sdkjs 9.4.0                                  | The host page (`engine/host/host.js`, ours) disables `_coSpellCheckInit` because no spelling dictionaries ship yet.                                                                                                                                                                                                                                                                                                                                                                                                         |
| 2026-10-09 | x2t (core 9.3.2, CryptPad WebAssembly build) | Unmodified. Run in a Web Worker by our `engine/host/x2t-worker.js`.                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| 2026-10-09 | core-fonts                                   | Unmodified fonts, stored in sdkjs's web font format (first 32 bytes obfuscated with sdkjs's fixed key, as DocumentServer does).                                                                                                                                                                                                                                                                                                                                                                                             |

Not used: ONLYOFFICE web-apps (editor UI), DocumentServer, desktop-sdk.
