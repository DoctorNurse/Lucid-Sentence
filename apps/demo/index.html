Summary

Lucid Sentence opens and saves .docx files and nothing else, so the file you send is the file your reader sees. This quarter we focused on round-trip fidelity, the ribbon on every screen size, and a calm, readable interface.

  • Ribbon commands render from one registry on desktop, tablet, and phone.
  • Every tab is reachable within three taps on a phone.
  • Pages stay white by default so what you see is what prints.
