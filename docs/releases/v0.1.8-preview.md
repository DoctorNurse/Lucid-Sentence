## What's new

- **You can start new documents again.** The app no longer opens straight into the sample. It opens on a start screen with **Blank document**, **New note**, **Open…**, and **Recent**. The sample is now just **Tour: Quarterly Notes**.
  - **Blank document** opens a new Word document (`Document1.docx`, `Document2.docx`, …) that you can type in and save with **Save** or **Save As**.
  - **New note** opens a blank notes page (`Notes1.docx`, …) where you can write with the pen, type, and record.
  - Tapping **Notes** while a Word document is open now starts a new note instead of only showing a message. The Notes bar also has a **New note** button.
  - Recordings now belong to the document you made them in, so a new note starts with no recordings.

Everything from 0.1.7-preview is here too: "Made with Lucid Sentence" on exported files (you can turn it off), open and save `.docx` with pictures, tables, headers and footers, print and PDF, spell check in 5 languages, the opt-in offline AI assistant, and per-CPU Android downloads.

On an older 32-bit (armv7) Android phone still on 0.1.3-preview or earlier, download `Lucid-Sentence-Android-armv7.apk` once yourself; updates work after that.

This is still a preview: not every ribbon command works with Word documents yet, handwriting inside Word documents is coming later, and the apps have had little testing on real devices.
