# Corpus sources

`01-basic.docx` … `10-comments.docx` are generated by `../make_corpus.py` (part of
this repository).

The `word-*.docx` files were saved by Microsoft Word (Word 2007 to 2016, Windows
and Mac; see each file's `docProps/app.xml`). They are test documents from two
open-source projects, copied unchanged and renamed with a prefix:

## Known differences

- `word-pd-comments-rich-para.docx`: its comment holds a picture. The converter
  alone keeps it; the editor keeps comment text only (ONLYOFFICE comments are
  plain text), so the picture in the comment is dropped when the document is
  saved from the editor.
